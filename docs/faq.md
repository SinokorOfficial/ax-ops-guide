# 자주 묻는 질문

> 읽는 사람: 현업

## 알림

| 질문 | 답 |
| --- | --- |
| 카드가 왔는데 화면은 멀쩡합니다 | 잠깐 스친 문제일 수 있습니다. 복구 카드가 오면 끝입니다. 자주 오면 전산팀에 알려 주십시오 |
| 복구 카드가 안 옵니다 | 화면에서 실제로 안 되는지 확인 → 방금 배포했다면 그 변경 확인 → 아니면 이슈로 전산팀에 |
| 다른 팀 앱 카드가 우리 채널에 왔습니다 | 긴급 등급의 백엔드 · 공용 DB 카드면 정상입니다(우리 앱도 영향받음). 아니면 전산팀에 알려 주십시오 |
| 카드의 「추정 원인」이 틀린 것 같습니다 | 추정입니다. 흔한 원인을 적어 둔 것이라 실제와 다를 수 있습니다 |
| `[테스트 — 무시하세요]` 카드는 무엇입니까 | 전산팀이 연결을 확인한 것입니다. 할 일이 없습니다 |
| 주말 · 밤에도 카드가 옵니까 | 옵니다. 아침 요약 카드는 평일에만 옵니다 |
| 공휴일에 「작업 멈춤 의심」이 왔습니다 | 업무 시간에만 도는 작업은 공휴일에 잘못 울릴 수 있습니다 |
| 알림이 너무 많습니다 | 채널 알림을 끄지 말고 이슈로 알려 주십시오. 기준을 조정합니다 |

## GitHub · 배포

| 질문 | 답 |
| --- | --- |
| main 에 바로 올려도 됩니까 | 안 됩니다. develop → main PR 로만 합칩니다. 합치는 순간 운영에 배포됩니다 |
| 배포가 실패했습니다. 운영이 멈췄습니까 | 아닙니다. 기존 버전이 계속 돕니다 |
| 배포했더니 이상합니다 | 직전에 잘 돌던 버전으로 다시 배포합니다(되돌리기). 그 뒤 원인 변경을 되돌리는 PR 을 올립니다 |
| 다른 팀 저장소가 안 보입니다 | 정상입니다. 팀은 자기 팀 저장소만 봅니다 |

## DB · Azure

| 질문 | 답 |
| --- | --- |
| DB 에 직접 붙어서 확인하고 싶습니다 | 안 됩니다. 필요한 조회를 「DB 요청」 이슈로 요청합니다 |
| 표를 하나 만들어야 합니다 | 명세를 파일로 올리고 「DB 요청」 이슈를 엽니다 |
| Azure 포털에 들어가야 합니까 | 아닙니다. 현업은 권한이 없고, 필요한 것은 이슈로 요청합니다 |
| 내 PC 에서 파일 올리기가 안 됩니다 | 정상입니다. 배포한 뒤 운영 화면에서 확인합니다 |
| 키 · 비밀번호를 받아야 합니다 | 채팅 · 이슈에 적지 않습니다. 「전산팀에 부탁」 이슈로 설정을 요청합니다 |

## 연락

| 질문 | 답 |
| --- | --- |
| 급한데 메신저로 말해도 됩니까 | 말해도 되지만, 받은 쪽이 이슈로 옮깁니다. 기록과 차례는 이슈에만 남습니다 |
| 이슈는 누가 닫습니까 | 현업이 화면에서 확인하고 닫습니다 |
| 이 문서가 틀렸습니다 | 이 문서 저장소에 이슈를 남겨 주십시오 |
