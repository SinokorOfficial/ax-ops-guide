# 새 앱 등록 체크리스트

> 읽는 사람: 전산팀

정식 배포하는 앱 · PC 에서 Azure 로 옮기는 작업에 똑같이 씁니다.

## 받기 전 확인

- [ ] 앱 표시 이름 · 담당 팀
- [ ] 저장소가 담당 팀에 연결돼 있는가
- [ ] 최소 서버 대수 (0 인가 1 이상인가)
- [ ] 정기 작업이 있는가 — 주기 · 성공/실패 기록 이름
- [ ] 실패 기록을 남기는가 ([준비 3가지](../new-app.md))

## 등록

- [ ] Teams 팀 채널 — 있으면 그 채널, 없으면 새로 만들고 **채팅형**으로
- [ ] 카드 자동화의 앱 목록에 한 줄 (앱 키 · 표시 이름 · 채널 · 담당 · 저장소)
- [ ] 저장소 이름이 앱 키와 다르면 저장소 → 앱 연결도
- [ ] 지표 규칙: 오류 응답 · 재시작 · 메모리
- [ ] 최소 서버 대수 1 이상이면 「서버 내려감」
- [ ] 정기 작업이 있으면 실패 · 미실행(또는 멈춤) 규칙
- [ ] 앱 고유 실패 기록이 있으면 백엔드 · 로그인 · DB 연결 규칙에 그 기록 추가
- [ ] 이 앱이 멈추면 같이 멈추는 팀이 있으면 긴급 사본 대상에 추가

## 확인

- [ ] 테스트 카드가 담당 팀 채널에 오는가
- [ ] 비공개 채널이면 전송 계정이 그 채널 멤버인가
- [ ] 아침 요약에 그 채널이 들어갔는가
- [ ] 실패 기록이 없으면 「로그 부족 — 코드 개선 필요」 안내 1회
- [ ] 이 문서의 [채널 표](../channels.md) 갱신

## 앱이 내려갈 때

- [ ] 그 앱의 규칙 삭제
- [ ] 앱 목록 · 채널 표에서 제거
